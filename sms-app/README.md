# Орлого SMS: банкны орлогын SMS-ийг сайт руу дамжуулагч

## APK болгох (Android Studio)
1. Android Studio → **File → Open** → энэ `SmsOrlogo` хавтсыг сонгоно.
2. Gradle sync дуусахыг хүлээнэ (анх удаа интернэтээс татна).
3. **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.
4. Гарсан файл: `app/build/outputs/apk/debug/app-debug.apk` → утас руу хуулж суулгана
   (утсан дээр "Тодорхойгүй эх сурвалжаас суулгах"-ыг зөвшөөрнө).

Хуучин апп суусан бол эхлээд устгаад суулгаарай (хуучин өгөгдлийн сан шинэтэй таарахгүй).

## Утсан дээр тохируулах
- SMS зөвшөөрөл өгнө.
- ⋮ → **Тохиргоо**:
  - Серверийн хаяг, Түлхүүр: Autoshop.mn → **Админ → Тохиргоо → SMS апп** хэсгээс хуулна
    (`https://web-mu-fawn-45.vercel.app/api/sms`)
  - Банкны дугаар: банкны SMS ирдэг дугаар (хоосон бол бүх дугаараас хүлээж авна)
- **Туршиж илгээх** → "✓ Сервер хүлээж авлаа" гарвал холбогдсон.
- Утасны тохиргооноос энэ аппыг **Battery optimization**-оос чөлөөлөөрэй (зарим утас background-д SMS-ийг хаадаг).

## Хуучин хувилбараас засварласан зүйлс
- `value` (гүйлгээний утга) нь дүнтэй адилхан хадгалагддаг байсан → одоо жинхэнэ утгыг (төлбөрийн кодыг) гаргана, бас бүтэн SMS-ийг илгээнэ.
- Урт SMS хэд хэдэн хэсэгт хуваагдаж ирэхэд таних боломжгүй болдог байсан → нэгтгэдэг болсон.
- Android 14+ дээр `registerReceiver` тугаас болж апп унадаг байсан → зассан.
- `assets/sms.db` файл, дутуу layout/menu/anim/theme файлууд → бүгдийг нэмсэн, DB-г код үүсгэнэ.
- Интернэт тасарсан үед мессеж алга болдог байсан → "Хүлээгдэж буй" гэж хадгалаад, апп нээх бүрт болон ⋮ → **Дахин илгээх**-ээр дахин илгээнэ.
- Нууц түлхүүр (`X-Api-Key`) нэмсэн, хэн ч таны API руу хуурамч "орлого" илгээж чадахгүй.
- Зарлагын SMS-ийг алгасна.

## Сайт руу илгээх формат
`POST` JSON, header `X-Api-Key: <түлхүүр>`:
```json
{ "money": "20000", "value": "482913", "body": "SMS-ийн бүтэн текст", "sender": "1800", "date": "2026-10-12 15:00:00" }
```
Хариу `{"code":0}` (эсвэл ямар ч 2xx) бол амжилттай гэж тэмдэглэнэ.
Сайтын тал (энэ репо): `web/src/app/api/sms/route.ts`, `supabase/fix-17-sms-income.sql`.

Банкны SMS-ийн хэлбэр өөр байвал `SmsParser.java`-г засна.
